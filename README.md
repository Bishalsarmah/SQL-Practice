# SQL Practice

This repository contains my SQL practice journey using PostgreSQL.

## Database

The practice database is based on an e-commerce dataset containing:

- Customers
- Products
- Orders

## Learning Roadmap

### Beginner
Questions 1-10

Topics:
- SELECT
- WHERE
- DISTINCT
- ORDER BY
- LIMIT
- BETWEEN
- AND / OR

### Intermediate
Questions 11-20

Topics:
- COUNT
- SUM
- AVG
- MIN
- MAX
- GROUP BY
- HAVING
- JOIN
- CASE
- Calculated columns

### Advanced
Questions 21-30

Topics:
- Subqueries
- CTEs
- Window functions
- RANK
- Complex JOINs
- Analytical queries

## Goal

Build strong SQL fundamentals and progress toward advanced SQL
and real-world data engineering problems.
